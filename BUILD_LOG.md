## 2026-08-16 — Research agent replaces regex reading

- Added `agent/research.py`: an LLM research agent that works to a per-metric analyst
  brief, retrieves candidate earnings releases, reads focused excerpts (capped at 6,000
  characters over at most 8 windows) and returns the figure the document reports for its
  own period together with the sentence it came from.
- Added a validation gate the agent cannot talk its way past: the supporting quote must
  appear verbatim in the source document, the value must be in the metric's plausible
  range, self-declared low confidence is refused, and a null answer is accepted as a
  null rather than replaced by a guess.
- Wired the agent into `history.py` as the primary reader. The deterministic parsers stay
  on as an independent cross-check; a period where the two disagree by more than 2% is
  dropped rather than silently resolved, and the agent never trades coverage away — if it
  finds less than the parser did, the parser's series is kept.
- Completions are temperature 0 and disk-cached under `agent/cache/research/`, so once the
  cache is warm the final run performs no network calls and reproduces offline.
- Added `tests/test_research.py`, which exercises every rejection path with a stubbed
  driver. Writing it caught two real defects: a shared cache served the first case's
  answer to every later case (so all six gates falsely appeared to pass), and
  `excerpt_for` overran its character budget by the length of its own separators.
- Verification: 36 tests pass. Ruff is clean on `agent/research.py`, `agent/history.py`
  and `tests/test_research.py`; 19 pre-existing findings remain in `extract.py`, `llm.py`,
  `signals.py`, `corpus.py` and `tests/test_run.py`.
- Not yet exercised end to end: no `OPENAI_API_KEY` was configured at the time of writing,
  so the agent path has been verified against a stubbed driver only. Until a key is set the
  pipeline runs on the deterministic parsers.
